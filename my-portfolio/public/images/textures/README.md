# Sidebar wood texture

`plywood.webp` is a resized WebP derivative of the 1K diffuse map from
[Plywood by Rob Tuytel, Poly Haven](https://polyhaven.com/a/plywood).
Source: https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/plywood/plywood_diff_1k.jpg
License: [CC0](https://polyhaven.com/license).

The colour wash is applied in CSS; the source texture retains its natural colours.
